# Jadde Marcelly | Advocacia Criminal

Site institucional estático, responsivo e sem dependências externas.

## Visualizar

Abra `index.html` no navegador ou execute um servidor local:

```bash
python3 -m http.server 8000
```

Depois, acesse `http://localhost:8000`.

## Estrutura

- `index.html`: conteúdo, metadados e integrações.
- `styles.css`: identidade visual e responsividade.
- `script.js`: menu mobile e animações discretas.
- `assets/`: materiais oficiais fornecidos para o projeto.

Todos os contatos, serviços, endereço e links usados no site foram informados no briefing.
